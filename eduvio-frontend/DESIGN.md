## Brand & Style
The design system is engineered for high-density information management and cognitive clarity. It targets university students who require a tool that feels both academically rigorous and technologically advanced. 

The aesthetic is **Modern Minimalist**, drawing heavily from the "Linear" and "Notion" schools of thought: prioritizing functional utility, intentional whitespace, and a monochromatic foundation punctuated by a single, purposeful accent color. The emotional response should be one of "calm productivity"—reducing the anxiety of a heavy workload through a clean, predictable, and highly organized interface.

## Colors
The palette is intentionally restrained to keep the focus on student content.
All colors are tokens in `src/index.css` (light values in `@theme`, dark overrides in `.dark`); the values above are generated from that file. Components use only token classes (`bg-surface-container-low`, `text-on-error-container`, …) — no hex, rgb, arbitrary `[#…]` values or default Tailwind colors (`green-500`, `white`, `black`), and no gradients. When a needed color is missing, add a token to both schemes.

- **Primary (`primary`):** primary actions, active states, links and progress. Muted blue (#2f5fd0); in dark mode a light blue with dark text on fills. Button hover is `hover:bg-primary/90`.
- **Primary container (`primary-container`):** a *tinted background* for chips, info boxes and icon tiles, with `on-primary-container` text. It is not a button fill.
- **Neutral / surface:** cool grays. `background`/`surface` for the canvas, `surface-container-lowest` for cards, `-low` … `-highest` for nested and hovered areas. `on-surface` for text, `on-surface-variant` for secondary text and placeholders.
- **Borders:** `outline-variant` for all structural divisions; `outline` only for icons and strong dividers (not for text — 3.5:1).
- **Status:** `success`, `warning`, `live` (an ongoing event), `error`. Each has a solid tone, a tinted `*-container` and an `on-*-container` text color; `success-soft` is the fill for graphics.
- **Midnight:** the dark highlight card ("Next up", auth brand panel): `midnight` background, `midnight-foreground` text, `midnight-muted` secondary text.
- **Scrim:** `bg-scrim/40` (or `/60`) behind modals and drawers.

### Usage rules
1. **Status as text** on a regular background: `on-*-container` (always for warning and live). The solid tone only where it reaches 4.5:1 — `text-error` is fine, `text-success` is only for icons.
2. **Badges / chips:** `bg-*-container` + `text-on-*-container`.
3. **Solid fill with text:** only `success`, `error`, `primary`, `live` with `text-on-*` (white in light mode, dark in dark mode).
4. **Graphics without text** (progress bars, timeline, status dots): `success-soft` for done/positive; `warning`, `live`, `error` and `primary` may be used as dots and bars.
5. **On the midnight card:** `text-midnight-foreground`, secondary `text-midnight-muted`; badges use `bg-midnight-foreground/8` with a `ring-midnight-foreground/15` instead of saturated colors.

Contrast: `node scripts/check-contrast.mjs` checks the pairs of these rules in both schemes (4.5:1 for text, 3:1 for large text and graphics). Run it after changing any color token.

## Typography
The system employs a dual-font strategy. **Geist** is used for headings and UI labels to provide a precise, technical edge that appeals to the modern student. **Inter** is used for body text and long-form notes to ensure maximum readability during long study sessions.

Hierarchy is established through weight and letter-spacing rather than dramatic size shifts. Use `label-sm` for metadata (e.g., "Course Code" or "Due Date") to maintain a structured, systematic feel.

## Layout & Spacing
The layout uses a **Fixed-Fluid Hybrid** model. 
- **Sidebar:** A fixed 260px left-hand navigation bar using a subtle off-white background.
- **Main Canvas:** A fluid area with a maximum content width of 1200px to prevent line lengths from becoming unreadable.
- **Spacing Rhythm:** Based on a 4px baseline grid. Standard component spacing should utilize 12px (3 units) or 16px (4 units) to maintain a compact, "SaaS-like" density.
- **Mobile:** The sidebar collapses into a bottom navigation bar or a hamburger menu, and horizontal padding reduces to 16px.

## Elevation & Depth
Depth is achieved through **Tonal Layering** and **Low-Contrast Outlines** rather than heavy shadows.
- **Level 0 (Base):** The main background (`background`).
- **Level 1 (Subtle):** Sidebar and secondary panels (`surface` / `surface-container-low`) with a right-hand border of 1px `outline-variant`.
- **Level 2 (Cards):** Floating elements use `surface-container-lowest`, a 1px border (`outline-variant`) and an extremely soft "Ambient Shadow": `0 1px 3px 0 rgba(0, 0, 0, 0.02), 0 1px 2px -1px rgba(0, 0, 0, 0.03)`.
- **Level 3 (Overlays):** Modals and dropdowns use a slightly more pronounced shadow and a 1px border to separate them clearly from the background canvas.

## Shapes
Following the modern SaaS aesthetic, the system uses a **Rounded (8px/0.5rem)** standard. 
- **Buttons and Inputs:** 8px (`rounded-md`).
- **Cards and Modals:** 12px (`rounded-lg`).
- **Outer Containers:** 16px (`rounded-xl`) when nested layouts are required.
This "soft-square" approach feels professional yet approachable, avoiding the clinical feel of sharp corners or the overly casual look of full pills.

## Icons
Only `lucide-react` (no image icons). Use `components/common/Icon`: `sm` 16 px in text and badges, `md` 20 px in navigation and buttons, `lg` 24 px in empty states and card headings; stroke 1.75 (also the `LucideProvider` default in `main.jsx`); color is `currentColor` from a text token; decorative icons are `aria-hidden`.
- One meaning, one icon: dashboard `LayoutDashboard`, subjects `BookOpen`, calendar/date `CalendarDays`, materials `FolderOpen`, planning `ListChecks`, profile/person `UserRound`, time `Clock`, deadlines `Bell`, course web page `Globe`.
- Material types (`components/materials/MaterialTypeIcon`): PDF `FileType2`, DOC `FileText`, SLIDES `Presentation`, NOTES `NotebookText`, RECORDING `Video`, LINK `Link`, on a tinted `*-container` tile.
- Navigation: active item `bg-primary/10 text-primary`, inactive `text-on-surface-variant` with a `surface-container` hover.

## Components
- **Buttons:** Primary buttons use `bg-primary text-on-primary` and `hover:bg-primary/90`. Secondary buttons use a surface fill with a 1px `outline-variant` border. Destructive buttons use `bg-error text-on-error`, or `text-error` with an `error/30` border when outlined.
- **Inputs:** Fields have a 1px `outline-variant` border on `surface-container-low` and turn `surface-container-lowest` with a `primary` border on focus; invalid fields use `border-error bg-error-container`.
- **Cards:** Subject/Course cards are minimalist. They should contain a small icon or color-coded tag in the top right. Content should be left-aligned with a clear `headline-md` title.
- **Sidebar Items:** The active item uses `bg-primary-fixed text-on-primary-fixed-variant`.
- **Chips/Badges:** Small, low-contrast pills for status (e.g., "In Progress," "Completed"). Use `bg-*-container` with `text-on-*-container` (e.g. `bg-success-container text-on-success-container`).
- **Progress Bars:** Use a thin 6px height with rounded ends to track study goals or course completion without dominating the visual space. Fill with `primary` or `success-soft` on a `surface-container` track.
